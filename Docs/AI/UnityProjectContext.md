# Colonization project context

Last inspected: 2026-10-13. Baseline commit: `496d577`.

## Environment and architecture

- Project root: `Z:\.Project Unity\GI-334-project-assignment`.
- Unity `6000.5.7f1`, URP `17.5.0`, Input System `1.20.0`, uGUI and TextMesh Pro.
- First-party code lives under `Assets/Scripts`. Classes use the global namespace and the default Unity assemblies; there are no first-party asmdefs.
- `GameManager` owns map generation, faction initialization, unit/town spawning, selection, exploration and turn state. `AIManager` runs the enemy turn coroutine on the same scene object. Terrain, faction and unit configuration use ScriptableObjects. `LandUnit` and `NavalUnit` inherit movement and pointer handling from `Unit`; `HexCalculator` calculates odd-row neighbors and nearby towns.
- `Map01` is the only enabled build scene. `GameManager.Start` initializes thirteen factions and selects England, generates a 50 by 60 map, spawns five Caravels and ten passengers, then creates Native towns and one unit per Native town.
- Camera movement uses the project-wide Move action; zoom uses the Zoom action, mouse wheel and Z/X. I toggles Hex coordinates. Tab cycles the player's ship, Veteran Soldiers and Hardy Pioneers and centers the camera. Left-click selects a player unit; right-click on an adjacent Hex orders movement. P queues forest clearing, B queues settlement construction, and Backspace ends the player turn.
