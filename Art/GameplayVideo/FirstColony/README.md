# First colony gameplay tutorial

Automated demonstration recorded from the project's actual Unity Play Mode rendering. The opening ship is staged near a suitable coast before recording; all shown moves, turn changes, landfall, forest clearing, town construction, worker assignment and harvesting use the existing gameplay/UI methods. This is a demonstration scenario, not a recording of physical mouse and keyboard input.

The MP4 has Thai captions and no narration. Source capture is 1280x720 at 4 sampled frames/second; output is H.264 at 24 fps with an additional caption band. Chapters.tsv records captions at exact captured frame numbers. The temporary demonstration state is discarded when returning to saved Map01 in Edit Mode.
