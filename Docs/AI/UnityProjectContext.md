Last inspected: 2026-10-14. Week 7 baseline commit: `260db09`; Week 8–13 changes are not yet committed.

## Environment and architecture

- Project root: `Z:\.Project Unity\GI-334-project-assignment`.
- Unity `6000.5.7f1`, URP `17.5.0`, Input System `1.20.0`, uGUI and TextMesh Pro.
- First-party code lives under `Assets/Scripts`. Classes use the global namespace and the default Unity assemblies; there are no first-party asmdefs.
- `GameManager` owns map generation, faction initialization, unit/town spawning, selection, exploration and turn state; GameManager.Combat.cs adds naval combat and first-contact coordination, while GameManager.EuropeUnits.cs creates owned hidden purchases and coastal AI targets. `AIManager` runs the enemy turn coroutine on the same scene object. `EuropeManager` owns market stocks, ship voyages and the Europe waiting-passenger queue. `UIManager` is partial: its existing file owns town UI, while UIManager.Europe.cs owns Europe/trade presentation and UIManager.EuropeUnits.cs owns purchase/train/order menus and waiting icons. `DialogManager` owns the queued modal naval/advisor/diplomacy/combat UI. Terrain, faction, unit, product and dialog configuration use ScriptableObjects. `LandUnit` and `NavalUnit` inherit movement and pointer handling from `Unit`; `HexCalculator` calculates odd-row neighbors, nearby towns and unmet adjacent factions.
- Enabled build scenes are MainMenu (entry/index 0), SelectNation and Map01. New Game resets to England; SelectNation stores one of five European IDs in `Settings.playerNationId` and advances through King command, preparation and departure screens before loading Map01. `GameManager.Start` initializes thirteen factions and selects that European faction, generates a 50 by 60 map, spawns five Caravels and ten passengers, then creates Native towns and one unit per Native town. Invalid selection IDs fall back to England.
- Camera movement uses the project-wide Move action; zoom uses the Zoom action, mouse wheel and Z/X. I toggles Hex coordinates. Tab cycles available on-map player units and centers the camera. Left-click selects a player unit; right-click on an adjacent Hex orders movement. P queues forest clearing, B queues settlement construction, Backspace ends the player turn, and E toggles EuropePanel. Town/Europe panels block map interaction; the naval confirmation also blocks ending a turn or opening Europe until answered.
